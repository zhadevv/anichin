# Support

## Before opening an issue

1. Check `docs/FAQ.md` — the most common questions are answered there.
2. Check `docs/ERRORS.md` if you're getting `success: false` and unsure why.
3. Check open and closed issues for the same slug/endpoint — Anichin's
   markup does change occasionally, and there's a decent chance someone
   already reported it.

## Getting help

- **Bug in scraping behavior / unexpected response shape** — open an issue
  using the Bug Report template (`.github/ISSUE_TEMPLATE/bug_report.md`).
  Include the exact method call and, if you know it, the anichin.cafe URL
  involved.
- **Missing feature or endpoint** — open an issue using the Feature
  Request template.
- **Usage question that isn't a bug** — open a regular issue or a
  Discussion (if enabled on the repo) rather than a Bug Report.

## Response time

This is maintained by one person in their spare time. There's no SLA —
please be patient, and consider opening a PR (see `CONTRIBUTING.md`) if
you're able to fix it yourself; that's almost always faster than waiting.
